# PLATFORM POSTING CHECKLISTS — ZARA VELASQUEZ
**Pre-flight checks for every platform. Run before every post.**

---

## INSTAGRAM FEED (Carousel / Single Image)

### Pre-Post
- [ ] Image: 1080x1350 (4:5) or 1080x1080 (1:1), JPEG 85%
- [ ] Color grade applied (Zara LUT: warm, film, grain)
- [ ] Face consistency verified (beauty mark, scar, pores, chain)
- [ ] Alt text written (accessibility)
- [ ] Caption: Hook in first line (before "more")
- [ ] Caption: 1 specific number/detail
- [ ] Caption: 1 vulnerable admission
- [ ] Caption: Ends with genuine question
- [ ] Hashtags: 3-5 niche (no #fyp #viral)
- [ ] Location tagged (if relevant)
- [ ] Tag brands organically (wearing/using)
- [ ] Paid Partnership tag ON if sponsored
- [ ] AI disclosure: #aiinfluencer #virtualinfluencer

### Post-Post (First 30 min)
- [ ] Reply to every comment with question
- [ ] Like first 20 comments
- [ ] Share to Story with "New Post" sticker + poll
- [ ] Add to relevant Highlight
- [ ] DM top 3 engagers: "Thanks for the love! What resonated?"

### Post-Post (24 hours)
- [ ] Check analytics: reach, engagement, saves, shares, profile visits
- [ ] Note top comment themes for future content
- [ ] Save high-performing post to "Best Of" Highlight

## INSTAGRAM REELS (9:16 Video)

### Pre-Post
- [ ] Video: 1080x1920, MP4, <100MB, 30fps, H.264
- [ ] Duration: 7-15 seconds (max 90s for educational)
- [ ] First frame: Hook (movement + text overlay)
- [ ] Captions: Burned in, synced, readable (yellow/white, outline)
- [ ] Audio: Platform library or royalty-free (Epidemic/Artlist)
- [ ] Volume: Voice > Music (voice clear)
- [ ] Cover: Custom thumbnail (face + emotion + 3-word text)
- [ ] Caption: Hook in first line
- [ ] Hashtags: 3 niche in caption, 5-7 in first comment
- [ ] Location: Relevant if local
- [ ] Paid Partnership tag if sponsored
- [ ] AI disclosure: Verbal in first 3s + #aiinfluencer
- [ ] Remixed/dueted relevant creator content (if applicable)

### Post-Post (First 30 min)
- [ ] Reply to every comment with question
- [ ] Like first 30 comments
- [ ] Share to Story: "New Reel" + question sticker
- [ ] Engage 10 relevant Reels (comment, don't just like)

### Post-Post (24 hours)
- [ ] Retention graph: Check drop-off points
- [ ] Saves/shares ratio (aim > 5%)
- [ ] Profile visits from Reel
- [ ] Link clicks if CTA included

## INSTAGRAM STORIES (Daily 15 frames)

### Per Frame
- [ ] Native format: 1080x1920
- [ ] Interactive element every 3 frames (poll, question, slider, quiz)
- [ ] Text: Readable (contrast, size, safe zones)
- [ ] Tag accounts mentioned
- [ ] Hashtag sticker (1 niche) + Location sticker
- [ ] Link sticker (if eligible) or "Link in bio" text

### Daily Sequence (15 frames)
1. **Morning hook** (5:30 AM matcha + "Good morning" poll)
2. **BTS prep** (what I'm working on today)
3. **Value drop** (tool tip / money tip / travel hack)
4. **Interactive** (poll: "Which outfit?" / "Coffee or matcha?")
5. **Vulnerable moment** (real talk, no filter)
6. **Social proof** (DM screenshot / fan comment / result)
7. **Content teaser** (coming today/tomorrow)
8. **Q&A** (question sticker: "Ask me anything")
9. **Break** (walk, stretch, view - no talk)
10. **Work session** (screen blur + "Deep work mode")
11. **Lunch/food** (local spot, no aesthetic pressure)
12. **Afternoon slump** (relatable struggle)
13. **Wrap up** (3 wins today)
14. **Evening wind down** (book, journal, no phone)
15. **CTA** ("New post live" / "Fanvue exclusive" / "Newsletter")

### Highlights Management
- [ ] Add daily frames to relevant Highlights
- [ ] Update Highlight covers monthly (consistent aesthetic)
- [ ] Archive > 30 days unless evergreen

## UNIVERSAL QUALITY GATE (EVERY PLATFORM)

Before ANY post goes live:

```
□ Face matches master references (beauty mark, scar, pores, asymmetry)
□ Hair color/style consistent (espresso + balayage, mid-back waves)
□ Tattoos present and correct (3 tattoos, correct placement)
□ Wardrobe from approved palette/signatures
□ Lighting natural (window/golden hour/overcast)
□ Color grade applied (warm, film-like, grain)
□ Composition follows Zara Frame
□ Imperfections visible (skin, hair, fabric, environment)
□ Correct dimensions for target platform
□ No ring light catchlights, no over-smoothing, no crushed blacks
□ Caption: Hook, Value, Vulnerable, Question
□ Hashtags: 3-5 niche, no spam tags
□ CTA clear and specific
□ Disclosure if sponsored/affiliate/AI
□ Alt text written
□ UTM parameters on all links
□ Scheduled in Buffer/Later (not manual)
□ Logged in content calendar with idea_id
```
