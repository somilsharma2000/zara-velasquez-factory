## PLATFORM-SPECIFIC ADAPTATIONS

### Instagram Feed (Carousel)
- Slide 1: Hook visual + headline text
- Slides 2-6: Value (1 concept per slide)
- Slide 7: Vulnerable close
- Slide 8: CTA (Save/Share/Link in bio)
- Caption: Expanded version + hashtags (3-5 niche)

### Instagram Reel (90 sec max)
- 0-1s: Visual hook + text overlay
- 1-3s: Verbal hook
- 3-60s: Value beats (cut every 2-3s)
- 60-75s: Vulnerable moment
- 75-90s: Question CTA + follow reminder
- Caption: 2 lines + hashtags + link in bio CTA

### TikTok (60 sec max)
- 0-0.5s: Visual hook (movement + text)
- 0.5-3s: Verbal hook
- 3-45s: Fast-paced value (jump cuts)
- 45-55s: Vulnerable/real moment
- 55-60s: Question + "Follow for part 2"
- Caption: Hook line + 3 niche hashtags + #greenscreen if applicable

### X/Twitter Thread
```
Tweet 1: Hook (280 chars max) 🧵👇
Tweet 2: Context (1-2 sentences)
Tweet 3-10: Value beats (1 per tweet, visual if possible)
Tweet 11: Vulnerable admission
Tweet 12: Lesson/framework
Tweet 13: CTA (Retweet/Reply/Link)
Tweet 14: "Threading this for my morning coffee ☕"
```

### LinkedIn
- Headline: Result + Timeframe (e.g., "$0 → $8.3K MRR in 8 months")
- Body: Professional frame, same voice, business lessons
- Format: Short paragraphs, bullet points, 1-2 line spacing
- Close: Question for comments
- Hashtags: 3-5 professional (#saas #bootstrapping #founderjourney)

### YouTube Shorts
- Title: Hook as headline (e.g., "I Quit My $60K Job With €3K Savings")
- 0-1s: Visual hook + title card
- 1-50s: Condensed story (fast cuts, captions)
- 50-60s: Question + Subscribe CTA
- Pinned comment: Link to newsletter/template
- Description: 2 lines + links + 3 hashtags

### Fanvue (Exclusive)
- Title: "What didn't make the feed: {Topic}"
- Body: Unfiltered, longer, actionable, behind-paywall
- Format: Long-form text + exclusive images/video
- CTA: "DM me your {specific struggle} — I reply to every one"

## QUALITY CHECK (EVERY CAPTION)

Before scheduling:
- [ ] Hook in first line (visible before "more")
- [ ] At least 1 specific number/detail
- [ ] At least 1 vulnerable/honest admission
- [ ] Ends with genuine question
- [ ] Voice check: Spanglish? Fragments? Casual?
- [ ] Platform formatted correctly
- [ ] Hashtags: 3-5 niche, no #fyp #viral
- [ ] CTA clear and specific
- [ ] Disclosure if sponsored/affiliate
- [ ] Alt text written for accessibility
